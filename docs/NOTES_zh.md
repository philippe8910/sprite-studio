# Sprite Studio

從一張角色立繪到遊戲可用 sprite sheet 的完整工作流網頁。雲端（fal.ai）與本機模型
（ComfyUI / A1111）都能用。獨立於原專案；fal.ai 金鑰在右上角「API 金鑰」填（也吃環境變數
`FAL_KEY` 與舊的 `%FAL_SECRETS_JSON%`）。

```
組合提示詞生立繪 → 選參考姿勢 + 提示詞 → 生成 5 張候選 → 挑一張
        → 套動作預設 → 生成影片 → 抽幀挑幀（即時播放）→ 不滿意重生成
        → 打包成 sprite strips + anims.json → 下載 / 複製進遊戲
```

## 啟動

```bat
cd sprite_studio
python server.py          ::  或直接雙擊 run.bat
```

開 <http://127.0.0.1:8765>。相依：`flask` `opencv-python` `numpy`（都已安裝）。

最上面那排是**專案分頁**，一個角色一個 tab：點擊切換、`＋` 開新專案、`⧉` 複製目前專案、
**在分頁上按右鍵**可以改名／開資料夾／刪除。分頁多了可以用滾輪橫向捲。
綠點＝已經有挑好幀的動作，後面的數字是動作數。

## 五個步驟

| 步驟 | 做什麼 |
|---|---|
| **1 角色生成** | 左邊用**組合式提示詞**（風格＋角度＋面向＋姿勢）＋可選風格參考圖生候選，點一張即設為專案立繪；右邊「結果預覽」只顯示選中的那張。**外部圖片不能蓋進來**，立繪只能從候選圖來。角色描述那句會填進所有提示詞的 `{C}` |
| **2 姿勢修改** | 左槽是專案立繪（不能拖圖換，只能用右上下拉切底圖）、右槽放姿勢參考（**可以直接拖檔案進去**）→ 套姿勢預設 → 一次生 5 張候選 → 點一張存成 `stand`/`walk`/`crouch`… |
| **3 動畫生成** | 每個動作一張卡：選姿勢源圖（**可以直接上傳外部圖片**）、模型、提示詞 → 生成影片 → 底部膠片挑幀、中央即時播放；框好的段可**另存為別的動作**（共用同一支影片） |
| **4 輸出** | 勾要打包的動作 → 產生橫向 strips + `anims.json` + zip → **右邊直接播放打包後的精靈圖**，可直接複製到指定資料夾 |
| **素材** | 所有專案、姿勢候選、影片都留著，隨時叫回來重挑幀或重生成 |
| **設定** | 本機模型串接（ComfyUI／A1111）、workflow 管理、抽幀與預設值 |

## fal.ai 金鑰與模型清單

**金鑰**：右上角「API 金鑰」按鈕（或設定頁最上面那格）貼上 `id:secret` 即可，存進
`settings.json`。優先序是**設定頁 → 環境變數 `FAL_KEY` → 舊的 `secrets.json`**。
按鈕上的小燈：綠＝驗證過、灰＝有金鑰但還沒驗、紅＝沒金鑰。驗證是拿一個不存在的
request id 去問狀態（金鑰錯回 401、對回 200），**不會產生費用**。

**模型清單是真的跟 fal.ai 要的**，不是寫死的：

- 清單 `GET https://fal.ai/api/models?categories=image-to-video｜image-to-image｜text-to-image`
- 每個模型的參數 `GET https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=<id>`

所以選單裡除了「內建配方」（實測過提示詞的那幾支）之外，還有一整組 **fal.ai 線上**
（目前圖片 400+、影片 200 支），新上架的模型不用改程式就能選。選了之後 **參數格會照
它的 OpenAPI schema 重排**：長度／解析度／比例的下拉選單直接吃 schema 的 enum，模型沒有
的欄位（cfg_scale、camera_fixed、negative_prompt…）整格藏起來，送出的 payload 也只帶它
認得的欄位。快取 12 小時，設定頁有「重抓模型清單」。抓不到線上清單時會退回內建配方，
payload 也退回原本寫死的組法，離線一樣能用。

## 角色生成（第一頁左半）

立繪一律從這裡生（**沒有上傳外部圖的入口**）：

- **風格參考**：拖圖進去（可多張）。提示詞裡的 style 句是叫模型抄**畫風**不是抄角色，
  負面詞也寫了「不要複製參考角色的臉／服裝」。留空＝純文字生成。
- **組合式提示詞**：四個下拉選單自動組成一句，選單一動就重組：
  - **風格** 像素風 sprite／高解析像素風／動漫平塗／照風格參考重畫／把參考圖轉像素風
  - **角度** 正側面（動畫首選）／3/4 前側／正面／3/4 後側／背面／俯視 45°
  - **面向** 朝右／朝左（這就是專案的朝向，改了直接存回專案；正面／背面／俯視會自動停用）
  - **姿勢** 站立待機／走路／跑步／跳躍／攻擊／受傷／蹲下／蹲下攻擊／不指定，
    **可以自己「＋ 姿勢」新增**（存在 `settings.json` 的 `char_poses`，所有專案共用）
  組出來的那句可以直接手改，改過就不再被選單覆蓋，按「重新組合」還原。
  角色手上拿什麼寫在**角色描述**（`{C}`）或「額外描述」，姿勢片段本身刻意不提武器。
- **模型會自動配合**：沒放參考圖時自動選文生圖模型、放了就選圖生圖模型（你自己動過選單就不再插手）。
  硬性要圖的模型在沒參考圖時會**直接把生成鈕鎖住**並說原因，不會白花錢送出去吃 422。
- 點候選圖＝設為專案角色立繪（自動轉綠幕），接著去「姿勢修改」。

## 原圖換姿勢（姿勢頁）

上面兩個槽就是生成時送給模型的兩張圖：

| 槽 | 內容 | 怎麼換 |
|---|---|---|
| 左：**角色原圖** | 模型照抄設計的來源 | 固定是「角色生成」選定的立繪；用右上下拉可以改用已完成的姿勢當底（不能拖外部圖進來換角色） |
| 右：**姿勢參考** | 要套用的身體姿勢 | 把姿勢圖**拖進去**（可一次多張，自動勾選）；也能點下方縮圖庫選 |

下方姿勢卡上有兩個按鈕：

- **當原圖** — 把這張設成左槽的角色原圖，接著生下一個姿勢（例如用 `crouch` 當底生 `crouch_attack`，比從站姿重畫穩）
- **做動作** — 直接跳到動作頁；已經有用這張姿勢的動作就選中它，沒有的話開新增面板並預選建議動作

## 本機模型（ComfyUI / A1111）

雲端模型（fal.ai）與本機模型在同一個下拉選單裡，選「本機 · …」就走本機、不計費。

**ComfyUI**：在 ComfyUI 用「Workflow → Export (API)」匯出 JSON，把要由這裡控制的欄位改成佔位符，
放進 `workflows/`（或在設定頁按「匯入 JSON／貼上」）：

| 佔位符 | 意義 |
|---|---|
| `%prompt%` `%negative%` | 正／負面提示詞 |
| `%image%` `%image2%` | 角色源圖／第二張參考圖（自動上傳到 ComfyUI） |
| `%seed%` `%steps%` `%cfg%` `%denoise%` | 取樣參數（每張圖 seed 自動 +1） |
| `%width%` `%height%` `%frames%` `%fps%` | 尺寸與影片長度 |
| `%model%` | 設定頁選的 checkpoint |

整格就是佔位符時會保留數字型別。內附 `workflows/comfy_img2img.json` 只用內建節點，
放進任何 SD1.5/SDXL checkpoint 就能用；影片 workflow 需要能輸出影片的節點
（VHS_VideoCombine、SaveWEBM、SaveAnimatedWEBP…），輸出會自動抽幀進挑幀流程。

**A1111 / Forge**：直接走 `/sdapi/v1/img2img`，只支援圖片，設定頁可選 checkpoint 與取樣器。

設定頁的「測試連線」會回報 ComfyUI 版本／顯卡／VRAM，或 A1111 目前載入的模型。

## 輸出預覽

輸出頁右側播的是**打包後的 strip 本身**，不是原始影片幀——所見即遊戲內所見。
可切動作、調 fps、水平翻轉（檢查左右版）、1–4× 縮放、換背景（棋盤格／深灰／淺灰／洋紅）。

## 挑幀工具

- **點擊**切換單幀、**Shift + 點擊**連選、**按住拖曳**刷選一整段
- 鍵盤：**空白鍵**播放／暫停、**← →** 逐幀（Shift 一次 10 幀）、**A** 切換選取、
  **[** **]** 設定區間、**O** 洋蔥皮、**?** 說明
- **洋蔥皮**：前一幀藍、後一幀紅，看動作連貫性
- **參考疊圖**：把 `../game/` 既有角色的同名動作半透明疊在後面（自動縮到同身高、腳底對齊），比姿勢與比例
- **水平翻轉／地面線**：檢查左右版與腳底基準
- **重新抽幀**：改色鍵參數（綠色下限／上限／綠優勢／飽和／亮度）後就地重抽，影片不用重生成
- **套用區間**：起／迄／步進（例如 30→46 步 2＝跑步週期）
- **循環偵測**：以選取的第一幀為基準，算出最接近無縫循環的週期（差異值越小越順）
- **跳躍分段**：依腳底 y 曲線自動找起跳／頂點／落地，一鍵建立 `rise`／`fall`／`land`
- **另存為動作**：把現在框選的那段幀存成另一個動作，**共用同一支影片、不重新生成也不花錢**。
  自動分段抓不準時就手動框 → 另存 `rise` → 再框 → 另存 `fall`…；單次動作記得關循環、開腳底對齊
  三個動作（自動開啟逐幀腳底對齊，否則會和遊戲物理疊加跳兩倍高）
- 幀縮圖右下的紅色小三角 = 偵測到暖色像素，多半是模型自己多加的火光特效，該段別選
- 藍色長條 = 腳底高度（越長跳越高）

## 打包管線

`色鍵 → 特效光清除 → 高度正規化 → 縮放校正 → 腳底對齊 → 站位對齊 → 共用裁切 → 描邊 → strips`

- **高度正規化**：Kling 保留來源長寬比、Seedance 裁成 1:1，直接 resize 成正方形會壓扁角色。
  這裡改成依畫面高度等比縮放後置中貼到共用畫布，再做對齊。
- **共用裁切框**：所有動作共用一個 bbox 與腳底基準線，遊戲內切狀態不會位移。
- `anims.json` 除了每個動作的 `frameW/frameH/count/fps/loop`，還有
  `_feetRatio`（腳底在幀內的比例）、`_anchorX`（身體軸）。

## 資料

```
data/projects/<專案>/
  project.json      設定、姿勢、動作、每次 take 的參數與統計
  source/           原始立繪 + 綠幕版
  poses/            挑好的姿勢立繪（生成影片的源圖）

  videos/           每個 take 的 mp4

```

刪除專案＝刪掉整個資料夾。所有資料都在本機。
設定存在 `settings.json`，ComfyUI workflow 存在 `workflows/`。

## 提示詞鐵律（已寫進預設）

- 動作預設是**通用的遊戲動作組**（idle／walk／run／jump／attack／hurt／crouch_idle／crouch_attack／roll／death），
  提示詞不假設角色帶什麼裝備——武器一律靠「保持設計 100% 相同」從立繪繼承
- 攻擊類一律禁特效（`no flash, no sparks, no trails`）並寫 `exactly one single attack`，遊戲端自己疊特效
- 待機不要寫 `idle animation`，會被重新詮釋成轉身站姿；只描述呼吸起伏
- 鎖朝向：`strict side profile facing right` ＋ Kling 負面 `turning around, facing the camera, front view, 3/4 view`
- 尾綴一律 `Camera fixed, no zoom, plain solid green screen background stays unchanged.`

## 局部替換（inpaint）

「姿勢」頁上方切到 **局部替換** 分頁：選底圖 → 用筆刷塗要重畫的區域 → 寫該區域的提示詞 → 生成。
塗到的地方才會重畫，其餘像素**原封不動**（實測遮罩外平均差異 0.03/255，等同無變化）。
適合換武器、改頭飾／表情、修單一部件，不用整張重生成。

- 筆刷大小、塗抹／擦除、清除、反轉，右下顯示遮罩覆蓋率
- 遮罩以底圖原始解析度送出，輸出尺寸＝底圖尺寸
- workflow 用 `comfy_inpaint.json`（`LoadImageMask → VAEEncodeForInpaint → KSampler →
  ImageCompositeMasked`），切到這個分頁會自動選 `kind: "inpaint"` 的 workflow
- A1111 走 `/sdapi/v1/img2img` 的 `mask` 欄位（`inpainting_fill: original`、`mask_blur: 6`）

## 本機實測紀錄（RTX 3060 Laptop 6GB）

`experiments/` 有八張對照圖，兩個模型跑**完全相同**的參數、seed、遮罩。

| checkpoint | 大小 | 結果 |
|---|---|---|
| SD1.5 base fp16 | 2.13 GB | denoise 0.25 勉強、0.40 開始走樣、0.55 臉崩成寫實風 |
| **Counterfeit-V2.5**（動漫向） | 4.27 GB | denoise **0.25–0.40 角色完整保留**、0.55 才開始亂；局部替換的劍也乾淨得多 |

速度（512px / 24 步）：兩個模型都是 **6–8 秒／張**。局部替換在底圖原尺寸（1254px）跑，約 **44 秒／張**。

**VAE 是個坑**：Counterfeit 這類合併模型的內建 VAE 會讓整張畫面發灰，綠幕從 BGR (71,178,82)
偏成 (78,167,90)——去背會受影響。改用外掛 `vae-ft-mse-840000.safetensors`（335 MB）後
背景回到 (70,177,82)，和原圖差 1。所以預設 workflow 是 `comfy_img2img_vae.json`，
設定頁多了 VAE 下拉（`%vae%` 佔位符）。

**參考疊合**兩個模型都會出現雙重武器的疊影——那是像素疊合這個方法本身的限制，不是模型問題。
要真正的特徵參考還是得裝 IPAdapter 或 ControlNet，匯出的 workflow 一樣吃 `%image2%`。

目前預設值：Counterfeit-V2.5 ＋ vae-ft-mse-840000 ＋ denoise 0.35 ＋ 512px。
